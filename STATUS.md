Compare with custom phase-vocoder/PSOLA routes on speech, transients, stereo, latency, CPU and formant independence. Reference https://github.com/Signalsmith-Audio/signalsmith-stretch. Do not treat upstream claims as plugin evidence.
- Granular and Ghost need controllable causal sample history, unlike a general-purpose pitch/time processor. Use a shared *implementation* of an instance-owned stereo ring (not shared mutable storage across instances/engines). Preallocate off audio thread, explicit age bounds, freeze prevents writing, zero for unavailable samples. Future grain playback must enforce valid read windows, account for advancing history, use normalized window overlap and bandlimited interpolation; reverse swell requires declared lookahead and aligned dry path. No arbitrary window/latency defaults adopted yet.

## P004 — GHOST core: reverse echo and anticipatory swell
Parent c1ed1467e1a3e2477efc284c0e6c54b7b4d3a6b9; Engineering immutable revision unchanged, START-HERE and product README reread. Reused bounded instance-owned History rather than duplicating the buffer implementation. Separate dry, echo, swell signals for later integration. Two complementary Hann heads read backward (source index decreases by one per output sample inside each segment); three weighted repetitions with bounded normalization. Independent reverse-swell FIR uses 96 stratified signed taps with rising exponential amplitude (40 dB across window), unit impulse energy, fixed provisional 160 ms lookahead and separate stereo signs. Inspired by sparse velvet-noise FIR methodology: Välimäki et al., Late Reverberation Synthesis Using Filtered Velvet Noise, Applied Sciences 2017, DOI 10.3390/app7050483; no borrowed implementation or claim of full filtered-velvet-noise algorithm. Fixed 180 ms echo window, fixed repeats and 160 ms latency are provisional design decisions, NOT a finalized musical or host latency contract; investigate lower-latency option and longer swells before finalization. True anticipatory swell precedes latency-aligned dry, never precedes physically arriving input. No dynamic host PDC or final routing yet. Core tail bound L+4W is measured relative to last input, not a verified VST3 tail API value. Parameter smoothing, gain staging of combined dry/wet, echo sync/motion, real voice quality, CPU and host verification remain open.
